# StockTradingSim

A full-stack stock trading simulation platform inspired by Zerodha, designed for educational and demonstration purposes. It allows users to simulate stock trades, track holdings, and explore trading workflows in a risk-free environment.

🔗 **Live Demo:** [zerodha-clone-174ee5.netlify.app](https://zerodha-clone-174ee5.netlify.app)

---

## Features

* **Interactive Dashboard:** View simulated market data, stock watchlists, and price changes.
* **Order Placement:** Buy and sell mock stocks with instant portfolio balance updates.
* **Portfolio & Holdings Management:** Track active holdings, order history, and net profit/loss.
* **Zerodha-Inspired UI:** Clean, intuitive interface mimicking real-world trading platforms.

---

## Tech Stack

* **Frontend:** React, HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / Mongoose
* **Deployment:** Netlify (Frontend)
